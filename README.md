# La Bóveda del Lector 🪄⚡

Una página de aterrizaje (landing page) temática inspirada en el mundo mágico de **Harry Potter**. Este proyecto demuestra habilidades de diseño web inmersivo, interactividad y maquetación creativa.

## 🌟 Características

*   **Atmósfera Mágica**: Uso de capas de fondo con efectos de niebla y profundidad (parallax).
*   **Elementos Interactivos**:
    *   Cortinas del Mapa del Merodeador que se abren.
    *   Pergaminos desplegables con información.
    *   Formulario de pedido temático "Hogwarts Express".
    *   Reproductor de video integrado en un espejo mágico.
*   **Diseño Premium**: Tipografía 'Cinzel' y paleta de colores cuidada para evocar fantasía clásica.

## 🛠️ Tecnologías Usadas

*   **HTML5**: Estructura semántica.
*   **CSS3**: Animaciones, posicionamiento absoluto/relativo, y diseño responsive.
*   **JavaScript / jQuery**: Lógica para interactividad, sliders y control de elementos multimedia.
